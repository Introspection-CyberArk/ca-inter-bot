# 📚 CA Intermediate Exam Bot

## 🎯 Overview
A Telegram bot designed to help CA Intermediate students prepare for exams through MCQ practice, concept explanations, and progress tracking.

## ⭐ Features
- ✅ 50+ MCQs across 6 CA Inter subjects
- 📝 Subject-wise topic practice
- 💡 Detailed concept explanations
- 📊 Progress tracking and analytics
- 🎯 Practice tests with random questions
- 🔍 Weak area identification
- ❓ Doubt solving

## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- Telegram account
- Bot token from @BotFather

### Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/ca-inter-bot.git
cd ca-inter-bot

# Install dependencies
pip install -r deploy/requirements.txt

# Create .env file
cp .env.example .env
# Edit .env with your bot token

# Run bot
python src/bot.py
